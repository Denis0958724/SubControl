# SubControl

Застосунок, який не дає платити за забуті підписки. Показує всі підписки в гривнях, нагадує за день до списання і підказує, як скасувати.

## Що вміє

**Безкоштовно**

- Список підписок: Netflix, Spotify, YouTube, MEGOGO, SWEET.TV, Київстар ТБ, iCloud, ChatGPT та інші — або будь-який свій сервіс.
- Сума на місяць і на рік у гривнях. Ціни в доларах і євро перераховуються за курсом monobank (якщо банк недоступний — за курсом НБУ).
- Циферблат місяця на головному екрані: видно, що вже списано і коли спишеться далі.
- Нагадування за день до списання з двома кнопками просто в сповіщенні: «Продовжую» або «Скасувати».
- Покрокові інструкції скасування для кожного сервісу, кнопки на сторінку скасування, підписки App Store і Google Play.
- До 7 активних підписок.

**Pro — 79 ₴ на місяць**

- Автопошук підписок у виписці monobank за 3 місяці.
- «Платимо разом»: скільки з кожного, якщо ділите підписку з родиною.
- Нагадування за 3 дні або за тиждень.
- Скільки завгодно підписок, експорт у таблицю (CSV).

## Що можна зробити автоматично, а що ні

| Бажання | Як зроблено | Чому саме так |
|---|---|---|
| Знайти активні підписки | Аналіз виписки monobank через особистий токен (лише читання) | Інші українські банки поки не дають такого доступу стороннім застосункам. Відкритий банкінг НБУ запускається — коли банки відкриють API, можна буде додати ПриватБанк та інших |
| Скасувати підписку в застосунку | Інструкція + пряме посилання на сторінку скасування + позначка «скасовано» | Жоден сервіс (Netflix, Spotify, Apple…) не дає стороннім застосункам скасовувати підписки за користувача |
| Заблокувати списання на картці | Підказка звернутися до банку, щоб зупинити регулярні списання продавця | Публічне API monobank і інших банків не вміє блокувати окремих продавців |

## Запуск на телефоні (для розробки)

1. Встановіть [Node.js](https://nodejs.org) 20 або новіший.
2. У папці проєкту:
   ```bash
   npm install
   npx expo start
   ```
3. Встановіть **Expo Go** з App Store або Google Play і відскануйте QR-код із терміналу.

## Перегляд у браузері

```bash
npm run preview:web
```

Збере одну сторінку `dist-preview/index.html`, яку можна відкрити в будь-якому браузері. Сповіщень і справжнього monobank у браузері немає — для них є демо-режим.

## Перевірки

```bash
npm test            # логіка: дати, суми, розпізнавання підписок у виписці
npm run typecheck   # TypeScript
```

## Публікація в App Store і Google Play

Збірка і відправка йдуть у хмарі через EAS — Mac і Android Studio не потрібні.

1. **Акаунти розробника**: Apple Developer Program (99 $ на рік) і Google Play Console (одноразово 25 $).
2. **Оплата Pro.** Магазини вимагають продавати цифрові підписки лише через їхні вбудовані покупки. Підключіть [RevenueCat](https://www.revenuecat.com) (`react-native-purchases`) і замініть заглушки в `src/lib/purchases.ts`. Створіть продукт `subcontrol_pro_monthly` за 79 ₴ у обох магазинах. Поки це не зроблено, кнопка «Оформити» вмикає Pro безкоштовно для перевірки.
3. **Політика конфіденційності**: текст у [`PRIVACY.md`](PRIVACY.md) — опублікуйте його за постійним посиланням (наприклад, через GitHub Pages) і впишіть свою пошту для звʼязку.
4. **Збірка і відправка**:
   ```bash
   npx eas-cli@latest login
   npx eas-cli@latest build --platform all --profile production
   npx eas-cli@latest submit --platform ios
   npx eas-cli@latest submit --platform android
   ```
5. **Сторінка в магазині**: назва, описи й ключові слова — у [`STORE.md`](STORE.md). Знімки екрана зручно робити з веб-превʼю або з телефона.
6. **Google Play для нового особистого акаунта** вимагає закрите тестування з групою тестувальників перед відкритим релізом — перевірте актуальні умови в Play Console.

## Будова проєкту

```
src/
  app/             екрани (Expo Router)
    index.tsx      головний: циферблат місяця і список
    add.tsx        вибір сервісу
    edit.tsx       ціна, валюта, дата, нагадування
    sub/[id].tsx   картка підписки
    cancel/[id].tsx  як скасувати
    import.tsx     автопошук у monobank
    settings.tsx, pro.tsx
  components/      циферблат, рядки, кнопки, календар
  lib/
    catalog.ts     сервіси, кольори, інструкції скасування
    detect.ts      пошук регулярних списань у виписці
    monobank.ts    запити до API monobank (1 запит на хвилину)
    notifications.ts  нагадування з кнопками
    money.ts, dates.ts, rates.ts
  store.ts         дані на телефоні (AsyncStorage)
```

Усі дані зберігаються тільки на телефоні. Токен monobank — у захищеному сховищі системи (Keychain / Keystore).
