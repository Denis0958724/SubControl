# SubControl

Застосунок, який не дає платити за забуті підписки. Показує всі підписки в гривнях, нагадує за день до списання і підказує, як скасувати.

## Що вміє

**Безкоштовно**

- Список підписок: Netflix, Spotify, YouTube, MEGOGO, SWEET.TV, Київстар ТБ, iCloud, ChatGPT та інші. Або будь-який свій сервіс.
- Сума на місяць і на рік у гривнях. Долари й євро перераховуються за курсом monobank. Якщо він недоступний, то за курсом НБУ.
- Циферблат місяця на головному екрані: видно, що вже списано і що ще попереду.
- Нагадування за день до списання з двома кнопками просто в сповіщенні: «Продовжую» або «Скасувати».
- Покрокові інструкції скасування, посилання на сторінку скасування, підписки App Store і Google Play.
- До 7 активних підписок.

**Pro: 79 ₴ на місяць (акція: перші 3 місяці по 75 ₴) або 690 ₴ на рік**

- Автопошук підписок у виписці: monobank, ПриватБанк та будь-який інший банк.
- «Платимо разом»: скільки з кожного, якщо ділите підписку з родиною.
- Нагадування за 3 дні або за тиждень.
- Скільки завгодно підписок, експорт у таблицю (CSV).

**Звуки.** Тихий клік на кнопках, перемикачі, «збережено», «скасовано», «знайдено». Мовчать, коли телефон на беззвучному, і не зупиняють музику. Вимикаються в налаштуваннях. Звуки синтезовані скриптом `scripts/make-sounds.py`, без чужих семплів і ліцензій.

## Автопошук у різних банках

| Банк | Як працює |
|---|---|
| monobank | Особистий токен з api.monobank.ua. Застосунок сам завантажує виписку за 3 місяці. Токен дає лише читання |
| ПриватБанк | Файл виписки з Приват24 (Excel або CSV). Застосунок читає його на телефоні |
| Будь-який інший | Те саме: файл виписки Excel або CSV. ПУМБ, Ощад, А-Банк, Sense тощо |

Чому Приват не напряму? Відкритий банкінг в Україні вже запущено, але банки пускають до виписки тільки застосунки з дозволом НБУ. Старе «мерчант-API» Приват24 для фізосіб не виглядає живим, на нього не варто будувати. Коли SubControl отримає дозвіл або підключиться через ліцензованого посередника, файл стане не потрібен.

Що вміє читати розбір файлів (`src/lib/statement`):

- `.xlsx` (новий Excel), `.xls` (старий бінарний Excel), «`.xls`», який насправді HTML-таблиця, XML Spreadsheet 2003, CSV;
- кодування UTF-8 і Windows-1251, роздільники `;`, `,`, табуляція;
- колонки знаходить за назвами («Дата», «Опис операції», «Деталі операції», «Сума в валюті картки», «Дебет/Кредит»…);
- суми в будь-якому записі: `-1 234,56`, `1,234.56`, `(199.00)`; дати текстом і числами Excel.

PDF не підходить: з нього таблицю не дістати. Застосунок прямо про це скаже.

## Що зробити автоматично не можна

- **Скасувати підписку за людину.** Netflix, Apple, Spotify й інші цього стороннім застосункам не дозволяють. Є інструкція, пряме посилання і позначка «скасовано».
- **Заблокувати списання на картці.** API банків такого не вміють. Застосунок радить звернутися до банку, щоб зупинити регулярні списання продавця.

## Поставити на телефон

**Android, без компʼютера.** На GitHub: вкладка Actions, «Тестовий APK для Android», кнопка Run workflow. Приблизно за пів години в розділі Releases зʼявиться «Тестова збірка N» з файлом `.apk`. Відкрийте цю сторінку з телефона (увійшовши в GitHub), завантажте файл і встановіть. Android попросить дозволити встановлення з браузера, це нормально для збірок не з Google Play. У тестовій збірці Pro вмикається безкоштовно.

**iPhone.** Apple не дає ставити застосунки повз App Store, тож варіантів два:

1. Expo Go, безкоштовно. Потрібен компʼютер з [Node.js](https://nodejs.org) 22:
   ```bash
   npm install
   npx expo start
   ```
   Встановіть **Expo Go** з App Store і відскануйте QR-код камерою. Телефон і компʼютер мають бути в одній Wi-Fi мережі.
2. TestFlight, як справжній застосунок. Потрібен Apple Developer Program (99 $ на рік), далі `eas build --profile preview --platform ios` або одразу production і TestFlight.

## Перевірки

```bash
npm test            # дати, суми, розпізнавання підписок, файли виписок різних банків
npm run typecheck   # TypeScript
npm run preview:web # одна сторінка для браузера, dist-preview/index.html
```

Зразки виписок для тестів генерує `scripts/make-statement-fixtures.py` (усі дані вигадані).

## Публікація в App Store і Google Play

Збірка і відправка йдуть у хмарі через EAS. Mac і Android Studio не потрібні.

1. **Акаунти розробника**: Apple Developer Program (99 $ на рік) і Google Play Console (одноразово 25 $).
2. **Оплата Pro.** Код уже готовий (`src/lib/purchases.ts`, RevenueCat). Лишилося створити товари:
   - App Store Connect і Google Play Console: дві автоподовжувані підписки в одній групі.
     - `subcontrol_pro_monthly`: 79 ₴ на місяць. Вступна пропозиція (introductory offer, pay as you go): 75 ₴ на місяць, 3 періоди. У Google Play це offer з фазою «discounted recurring payment» на 3 місяці.
     - `subcontrol_pro_yearly`: 690 ₴ на рік.
     - Apple має фіксовану сітку цін для кожної країни. Якщо 75, 79 чи 690 ₴ там немає, оберіть найближчу. Застосунок показує ціни, які віддає магазин, тож код правити не треба.
   - [RevenueCat](https://www.revenuecat.com): проєкт, обидва магазини, entitlement `pro` з обома товарами, offering `default` з пакетами Monthly і Annual.
   - Ключі RevenueCat (публічні, `appl_…` і `goog_…`) додайте в EAS:
     ```bash
     npx eas-cli@latest env:create --name EXPO_PUBLIC_REVENUECAT_IOS_KEY --value appl_xxx --environment production
     npx eas-cli@latest env:create --name EXPO_PUBLIC_REVENUECAT_ANDROID_KEY --value goog_xxx --environment production
     ```
   - Без ключів робоча збірка нічого не продає і нічого не дарує. Безкоштовний Pro буває лише в тестових збірках (`EXPO_PUBLIC_TEST_PRO=1`, профіль `preview`).
3. **Політика конфіденційності**: текст у [`PRIVACY.md`](PRIVACY.md), у застосунку він теж є (Налаштування, внизу). Опублікуйте його за постійним посиланням для сторінки в магазині. Впишіть пошту для звʼязку в `PRIVACY.md` і `src/lib/links.ts` (`CONTACT_EMAIL`).
   - App Store, «App Privacy»: збираються лише Purchases (історія покупок), не повʼязані з особою, для роботи застосунку. Трекінгу немає.
   - Google Play, «Data safety»: те саме, Purchase history, шифрування при передачі, можна видалити.
4. **Збірка і відправка**:
   ```bash
   npx eas-cli@latest login
   npx eas-cli@latest build --platform all --profile production
   npx eas-cli@latest submit --platform ios
   npx eas-cli@latest submit --platform android
   ```
5. **Сторінка в магазині**: назва, описи й ключові слова в [`STORE.md`](STORE.md).
6. **Google Play для нового особистого акаунта** вимагає закрите тестування перед відкритим релізом. Актуальні умови дивіться в Play Console.

## Будова проєкту

```
src/
  app/               екрани (Expo Router)
    index.tsx        головний: циферблат місяця і список
    add.tsx          вибір сервісу
    edit.tsx         ціна, валюта, дата, нагадування
    sub/[id].tsx     картка підписки
    cancel/[id].tsx  як скасувати
    import.tsx       автопошук: вибір банку, токен або файл
    pro.tsx          два тарифи, акція, оплата через магазин
    settings.tsx, privacy.tsx
  components/        циферблат, рядки, кнопки, календар
  lib/
    statement/       читання файлів виписки (xlsx, xls, csv, html)
    detect.ts        пошук регулярних списань
    banks.ts         банки та інструкції, як дістати виписку
    monobank.ts      запити до API monobank (1 запит на хвилину)
    catalog.ts       сервіси, кольори, інструкції скасування
    notifications.ts нагадування з кнопками
    purchases.ts     RevenueCat: тарифи, покупка, відновлення
    feedback.ts      звуки й вібрація
  store.ts           дані на телефоні
```

Усі дані зберігаються тільки на телефоні. Токен monobank лежить у захищеному сховищі системи (Keychain або Keystore). Файли виписок читаються на телефоні й нікуди не надсилаються.
